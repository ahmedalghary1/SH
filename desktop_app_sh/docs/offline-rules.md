# قواعد Offline-first

1. تحفظ كل عملية محلية في SQLite قبل محاولة رفعها.
2. تضاف العمليات المؤثرة إلى `sync_queue` مع `idempotency_key`.
3. يعمل التطبيق بدون إنترنت بعد تسجيل دخول سابق ناجح.
4. عند إنشاء فاتورة محليًا يتم إنقاص `local_stock` فورًا.
5. عند فشل المزامنة لا تحذف العملية، بل تنتقل إلى حالة `failed` أو `conflict`.
6. عند نجاح مزامنة عميل أو فاتورة يتم حفظ `server_id` وربط السجلات التابعة به.
7. لا تظهر تفاصيل تقنية للمستخدم العادي داخل شاشة البيع.
